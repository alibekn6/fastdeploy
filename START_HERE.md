# Начните здесь 👋

Эта папка — **готовая основа для вашей собственной веб-платформы**. Программировать не
нужно: весь код пишет Claude (ИИ-ассистент). Вы описываете, что хотите, обычными словами —
Claude строит это и показывает в браузере. Писать можно на русском, казахском или
английском — Claude понимает любой.

## Настройка компьютера — один раз, ~15 минут (Mac)

Если компьютер уже настраивал разработчик — пропустите этот раздел и идите к
«Как начать». Если у вас обычный Mac, где ничего не установлено, — выполните шаги
по порядку. Ничего понимать не нужно: просто копируйте команды целиком и вставляйте.

1. **Откройте Терминал.** Нажмите `Cmd + Пробел`, наберите «Терминал» и нажмите
   **Enter**. Откроется окно, куда вставляются команды.

2. **Установите Homebrew** — это «магазин программ» для команд. Вставьте в Терминал
   строку целиком и нажмите **Enter**:

   ```
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

   Mac спросит пароль вашего компьютера. **Когда вы его печатаете, на экране ничего
   не появляется — это нормально**, просто наберите пароль и нажмите Enter. Дальше
   жмите Enter, когда установщик попросит, и подождите несколько минут.

3. **Подключите Homebrew.** Вставьте и нажмите **Enter**:

   ```
   echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile && eval "$(/opt/homebrew/bin/brew shellenv)"
   ```

   (Если Mac старый, до 2020 года, и команда ругается — просто закройте Терминал и
   откройте заново.)

4. **Установите всё нужное одной командой** (Node, pnpm, git и сам Claude Code):

   ```
   brew install node pnpm git && brew install --cask claude-code
   ```

   Это займёт несколько минут — дождитесь, пока в Терминале снова можно печатать.

5. **Получите папку проекта.**
   - Если вам прислали **ссылку на репозиторий** — вставьте в Терминал
     `git clone ` (с пробелом в конце), затем ссылку, и нажмите Enter. Папка
     появится в вашей домашней папке.
   - Если вам прислали **архив (zip)** — распакуйте его двойным кликом и положите
     папку, например, в «Документы».

6. **Проверка.** Наберите в Терминале `claude --version` и нажмите Enter. Если
   появилась строчка с номером версии — всё готово. Если пишет «command not found» —
   закройте Терминал, откройте заново и попробуйте ещё раз.

Больше эти шаги повторять не придётся.

## Как начать

1. Откройте Терминал **в папке проекта**. Самый простой способ: наберите `cd `
   (с пробелом), перетащите папку проекта мышкой прямо в окно Терминала и нажмите
   **Enter**. (Или: правый клик по папке → *Службы* → *Новый терминал по адресу папки*.)
2. Наберите `claude` и нажмите **Enter**. При первом запуске откроется браузер и
   попросит войти в аккаунт Claude — войдите (нужна подписка Claude Pro или Max).
3. Поздоровайтесь и опишите своими словами, что хотите построить. Например:

   > «У меня маникюрный салон. Хочу сайт, где клиенты записываются к мастерам.»

   > «Мне нужна платформа, где студенты покупают курсы и смотрят уроки.»

Claude всё настроит, откроет ваш сайт в браузере и начнёт строить.
Дальше — просто продолжайте разговор:

| Вы пишете | Что происходит |
| --- | --- |
| «Покажи мой сайт» | Сайт открывается в браузере |
| «Добавь страницу с ценами» | Claude строит её и показывает |
| «Сделай кнопки больше» / «Не нравятся цвета» | Claude меняет |
| «Опубликуй сайт» | Сайт появляется в интернете по реальной ссылке |

## Полезно знать

- **Пока сайт работает на образцовых данных.** Записи, входы и списки — имитация, чтобы
  вы могли спроектировать и проверить всё. Когда позже подключится настоящий бэкенд
  (база данных), одна настройка переведёт сайт на реальные данные — ничего из
  построенного не потеряется.
- **Сломать ничего нельзя.** Всё сохраняется с историей версий, и Claude может отменить
  любое изменение. Экспериментируйте смело.
- **Если что-то выглядит страшно** (красный текст, ошибки) — не пугайтесь: скопируйте это
  Claude и напишите «почини».
