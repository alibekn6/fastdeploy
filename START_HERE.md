# Начните здесь 👋

Эта папка — **готовая основа для вашей собственной веб-платформы**. Программировать не
нужно: весь код пишет Claude (ИИ-ассистент). Вы описываете, что хотите, обычными словами —
Claude строит это и показывает в браузере. Писать можно на русском, казахском или
английском — Claude понимает любой.

Инструкция для Mac (у вас почти наверняка Mac). Всё делается один раз, займёт ~15 минут.

---

## Шаг 0. Две минуты про Терминал

Терминал — это обычное приложение Mac: окно, в которое вставляют текстовые команды.
Вам не нужно их понимать — только копировать и вставлять.

- **Открыть Терминал:** нажмите `Cmd + Пробел`, наберите «Терминал» (или «Terminal»)
  и нажмите **Enter**.
- **Вставить команду:** скопируйте её здесь целиком (`Cmd + C`), кликните в окно
  Терминала, вставьте (`Cmd + V`) и нажмите **Enter**. Enter = «выполнить».
- **Команда «думает»** — просто ждите, пока в окне снова можно будет печатать.
- **Что-то спрашивает или ругается красным** — не страшно. Дочитайте инструкцию ниже
  или, если уже дошли до Claude, скопируйте ему текст и напишите «почини».

## Шаг 1. Заведите аккаунты (в браузере, без Терминала)

1. **Claude** — зарегистрируйтесь на <https://claude.ai> и оформите подписку
   **Pro** (или Max). Без подписки Claude Code работать не будет.
2. **Vercel** (нужен только когда захотите опубликовать сайт в интернете —
   можно отложить): бесплатный аккаунт на <https://vercel.com/signup>,
   проще всего «Continue with Email».

## Шаг 2. Установите Homebrew

Homebrew — «магазин программ» для Терминала, через него поставим всё остальное.
Вставьте в Терминал строку целиком и нажмите **Enter**:

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

- Mac спросит **пароль вашего компьютера**. Когда вы его печатаете, **на экране ничего
  не появляется — это нормально**: наберите пароль вслепую и нажмите Enter.
- Дальше жмите Enter, когда установщик попросит подтверждение, и ждите несколько минут.

Затем «подключите» Homebrew — вставьте и нажмите **Enter**:

```
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile && eval "$(/opt/homebrew/bin/brew shellenv)"
```

(Если Mac старше 2020 года и команда ругается — закройте Терминал, откройте заново
и продолжайте со следующего шага.)

## Шаг 3. Установите всё нужное одной командой

Это Node, pnpm, git (инструменты, которыми пользуется Claude) и сам Claude Code:

```
brew install node pnpm git && brew install --cask claude-code
```

Займёт несколько минут. Если именно часть про `claude-code` не сработала — запасной
вариант:

```
curl -fsSL https://claude.ai/install.sh | bash
```

## Шаг 4. Получите папку проекта

- Вам прислали **ссылку на репозиторий** (вида `https://github.com/...`)?
  Вставьте в Терминал `git clone `, **с пробелом в конце**, затем ссылку, и нажмите
  Enter. Например:

  ```
  git clone https://github.com/alibekn6/fastdeploy.git
  ```

  Папка появится в вашей домашней папке.
- Вам прислали **архив (zip)**? Распакуйте двойным кликом и положите папку,
  например, в «Документы».

## Шаг 5. Проверка

Наберите в Терминале:

```
claude --version
```

Появилась строчка с номером версии — всё готово. Пишет `command not found` —
закройте Терминал, откройте заново и попробуйте ещё раз.

Шаги 0–5 больше повторять не придётся.

## Как начать строить

1. Откройте Терминал **в папке проекта**. Самый простой способ: наберите `cd `
   (с пробелом), перетащите папку проекта мышкой прямо в окно Терминала и нажмите
   **Enter**. (Или: правый клик по папке → *Службы* → *Новый терминал по адресу папки*.)
2. Наберите `claude` и нажмите **Enter**. При первом запуске откроется браузер и
   попросит войти в аккаунт Claude из шага 1 — войдите.
3. Поздоровайтесь и опишите своими словами, что хотите построить. Например:

   > «У меня маникюрный салон. Хочу сайт, где клиенты записываются к мастерам.»

   > «Мне нужна платформа, где студенты покупают курсы и смотрят уроки.»

Claude всё настроит, откроет ваш сайт в браузере и начнёт строить.
Дальше — просто продолжайте разговор:

| Вы пишете | Что происходит |
| --- | --- |
| «Покажи мой сайт» | Сайт открывается в браузере |
| «Добавь страницу с ценами» | Claude строит её и показывает |
| «Сделай кнопки больше» / «Не нравятся цвета» | Claude меняет |
| «Опубликуй сайт» | Сайт появляется в интернете по реальной ссылке (понадобится аккаунт Vercel из шага 1) |

Если Claude сам о чём-то спрашивает разрешения («Allow…?») — это его встроенная
осторожность: прочитайте и подтвердите, либо спросите его же «что это значит?».

## Полезно знать

- **Пока сайт работает на образцовых данных.** Записи, входы и списки — имитация, чтобы
  вы могли спроектировать и проверить всё. Когда позже подключится настоящий бэкенд
  (база данных), одна настройка переведёт сайт на реальные данные — ничего из
  построенного не потеряется.
- **Сломать ничего нельзя.** Всё сохраняется с историей версий, и Claude может отменить
  любое изменение. Экспериментируйте смело.
- **Если что-то выглядит страшно** (красный текст, ошибки) — не пугайтесь: скопируйте это
  Claude и напишите «почини».
- **Застряли на любом шаге** — напишите Claude (можно даже в браузере на claude.ai),
  что видите на экране, и он подскажет.
